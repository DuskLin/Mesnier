## Purpose

定义 Mesnier 对话与看板共享工作记录的基础契约，使 Work 与 Coding 任务能够沿同一会话和执行历史推进，避免切换视图造成重复工作，并将产物检查、任务验收与运行时是否正常退出清楚区分。

## ADDED Requirements

### Requirement: 支持普通目录与代码项目

系统 SHALL 允许用户选择本地工作目录并发起任务；Work 任务不要求目录为 Git 仓库。系统 SHALL 在执行前核对工作目录是否存在且可访问，不能因目录异常静默使用其他位置。

#### Scenario: 在普通目录完成 Work 任务

- **WHEN** 用户选择一个可访问的非 Git 目录并要求整理资料或生成文本文件
- **THEN** 系统允许发起执行并在该目录关联产物，不要求初始化 Git 仓库

#### Scenario: 工作目录不可用

- **WHEN** 指定目录已被删除或当前进程无权访问
- **THEN** 系统说明目录问题并阻止任务开始，不改用应用目录或其他项目目录执行

### Requirement: 对话和看板共享同一次工作

系统 SHALL 允许用户将现有对话创建为或关联到看板任务，使任务保留同一会话、执行历史和产物引用。视图切换和重复关联操作 SHALL 不复制会话、创建重复任务或重启执行。

#### Scenario: 执行中将对话关联为任务

- **WHEN** 用户将正在执行的对话关联为看板任务并进入卡片详情
- **THEN** 卡片显示同一会话和同一次执行，已有消息、权限请求与产物继续可见，不再次发送原任务

#### Scenario: 返回对话或重复关联

- **WHEN** 用户从卡片返回对话，或再次对已关联的对话发起关联操作
- **THEN** 系统打开现有关联并展示最新状态，不增加新的执行或重复卡片

### Requirement: 基础看板与明确操作

系统 SHALL 提供待办、进行中、待验收和已完成的任务视图，并单独显示阻塞、失败、取消及待核对的执行状态。卡片 SHALL 展示标题、Agent 指派与执行概况，支持基础筛选和查看任务详情。启动、取消、重试和验收 SHALL 有明确入口；拖拽或修改指派不得隐式执行这些动作。

#### Scenario: 查看与筛选任务

- **WHEN** 用户按任务状态或 Agent 筛选看板并打开一张卡片
- **THEN** 系统显示匹配任务及其关联对话、执行记录、待处理请求和产物，无需复制任务才能查看详情

#### Scenario: 修改进行中任务的指派或卡片状态

- **WHEN** 用户修改正在执行任务的 Agent 指派或拖拽卡片
- **THEN** 系统保留当前执行的指派和配置快照；只应用符合执行与验收规则的任务变更，说明被拒绝的操作，不自动启动或停止运行

#### Scenario: 通过拖拽尝试绕过验收

- **WHEN** 用户将尚未验收的任务拖到已完成列
- **THEN** 系统要求执行明确的验收操作或拒绝该移动，不将拖拽本身记录为验收通过

### Requirement: 任务验收独立于执行结束

系统 SHALL 保留一个任务的多次执行历史，并分别记录任务验收和执行结果。执行正常结束最多使任务进入待验收；只有用户确认结果满足目标后才能标记为已完成。失败或取消 SHALL 保留原因和已有产物，不自动视为验收通过。

#### Scenario: 执行正常结束

- **WHEN** Agent 正常结束执行并返回结果
- **THEN** 系统展示待检查的结果与执行记录，任务保持待验收而非直接已完成

#### Scenario: 用户验收或要求继续工作

- **WHEN** 用户查看结果后确认通过，或提出后续修改
- **THEN** 确认通过时记录验收并完成任务；提出修改时保留原执行历史并由明确的提交操作发起后续执行

#### Scenario: 执行失败或取消

- **WHEN** 当前执行失败或被确认取消
- **THEN** 系统展示该执行状态和原因，任务保持未验收，后续重试不会覆盖旧记录

### Requirement: 基础产物可追溯

系统 SHALL 记录执行生成或修改的基础文件引用，使用户能从关联对话与任务详情查看相同的产物来源；首版至少覆盖文本文件和文件变更摘要。系统 SHALL 说明无法预览、已移动或已删除的文件，不伪装成仍可查看的交付物。

#### Scenario: 在两种视图查看交付物

- **WHEN** 用户从对话和任务详情分别查看同一次执行产生的文本文件或文件变更
- **THEN** 两种入口显示一致的文件引用和执行来源，可访问的文本提供内容查看，其他文件明确其打开方式或预览限制

#### Scenario: 产物已不存在

- **WHEN** 已关联的文件被外部移动或删除
- **THEN** 系统保留历史来源并提示文件不可访问，不把旧引用当作已经验证存在的当前产物
