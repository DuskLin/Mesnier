## 实际结果

模型配置增改删与默认切换、项目和会话、草稿隔离、中文输入不误发送、看板编辑筛选、两种主题与最小窗口均通过。工具授权在 Chat → Board → Chat 中保持相同执行和请求身份；重复点击只处理一次，拒绝 Write 不写文件。Work 目录的 Git 检查退出 128；独立 Coding 仓库返回 `true`，两类目录都实际执行了审批与文件验证。

真实文本产物可预览、复制和刷新，文件丢失会报错。系统剪贴板完成已知文本核对后恢复，原内容未写入证据。执行成功先进入待验收，用户明确确认后才完成；Coding 修改保留真实 Git diff，未经过用户验收的任务仍为待验收。

Bash 已写出的文件在取消后保留。修改默认模型不改变活动执行快照，后续重试使用新模型且保留原取消记录。正常关闭收到取消确认后恢复 `cancelled`；实际 `SIGKILL` 后原执行恢复 `interrupted`，没有残留独立运行时或自动重放，明确输入能恢复原生会话。服务回显的测试凭据被脱敏。

缺失用量、供应方显式零值、包含缓存的正数和旧会话恢复后再次缺失均通过界面验证：分别显示“未提供”、`0 tokens`、输入 `21 tokens`／输出 `8 tokens`，不沿用上一执行的统计。
