# Mesnier 0.1.0 使用说明

Mesnier 把文件工作、代码任务、对话和看板放在一个桌面工作台。当前安装包适用于 Apple Silicon Mac；应用内置 Agent 运行时，模型服务需要自行配置。

## 安装与打开

打开 `Mesnier-0.1.0-arm64.dmg`，把 Mesnier 拖到“应用程序”，然后双击打开。也可以解压 ZIP 后移动 `Mesnier.app`。首次启动无需启动开发服务器，不要求安装 Node 或 Kimi CLI。

当前包使用本地临时签名，没有 Apple Developer ID 签名或公证，适用于本机交付；通过其他渠道下载到另一台 Mac 后可能需要在系统“隐私与安全性”中确认来源。不要关闭整机安全检查。Windows、Intel Mac 和 Linux 安装包尚未交付。

## 第一次配置

1. 点击左下角“设置与模型”，在“模型服务”页点击“新增”，添加一个模型配置。已有配置从左侧模型列表选择；“外观”和“关于 Mesnier”位于设置分类栏。切换分类保留模型草稿，返回工作台或选择其他模型时会提示处理未保存修改。
2. 填写名称、协议、服务地址和模型名称。OpenAI 兼容服务通常使用以 `/v1` 结尾的地址；Anthropic 接口可填写服务根地址或 `/v1` 地址。
3. 填写 API Key。本地无认证服务可以留空。上下文长度按服务实际能力填写，不要直接套用其他模型的数值。
4. 点击“保存并验证”。通过表示服务返回了要求的基础工具调用，复杂任务能力还需通过实际结果判断。
5. 添加项目并选择一个可读写目录，再创建会话、描述目标并发送。

协议提供 OpenAI Chat Completions、OpenAI Responses 和 Anthropic 三种入口。本版已用本地 Qwen3-4B-Instruct-2507 的 OpenAI Chat Completions 接口完成真实文件与代码任务；其他模型服务和商业账号尚未逐一验证；当前不提供订阅登录或账号导入，不导入已有 Kimi 账号或配置。

## 对话、权限与文件

工作台会逐步显示回复、工具事件、运行状态和文件产物。文件写入、编辑和命令执行会显示审批，检查文件路径或命令后选择批准或拒绝；拒绝只针对该次操作。读取行为沿用内核权限规则。工具运行在本机，审批不等于系统沙箱。

执行中可取消。界面先进入“正在取消”，收到停止确认后才显示已取消；已发生的文件修改不会自动回滚。如果应用或运行时异常退出，会保留中断记录，提示先检查文件再明确继续。运行期间的新输入保留在编辑框，当前版本不插入正在执行的回合。

右侧产物来自任务前后文件变化，可预览文本或在 Finder 中查看。当前预览最多读取 256 KiB；二进制、已删除、移出项目或无法访问的文件会说明原因。产物追踪跳过 `.git`、`node_modules`、`.venv` 等目录，超过 20,000 个文件时需要选择更具体的工作目录。

## Chat 与 Board

对话可以关联为看板任务。两个视图使用同一会话、执行和文件记录，切换不会再运行一次任务。任务支持 Agent 指派、筛选与详情查看。

执行成功后任务进入“待验收”。核对文件和验收标准后，点击验收完成；运行结束不会自动代表任务完成。失败或取消后，可以修正模型设置、目录或目标，再显式重试；重试保留原记录并创建关联的新执行。

当前按串行队列执行任务。新执行捕获当时的模型与 Agent 配置，后续修改默认模型不会悄悄改变已经排队的任务。

## 数据、备份与恢复

默认数据根目录为 `~/.mesnier`：

| 位置 | 内容 |
| --- | --- |
| `state.json`、`state.json.bak` | 项目、会话、任务、执行、事件和产物记录，以及前一版状态 |
| `credentials.json` | 经 macOS 系统能力加密的模型凭据 |
| `runtime/agent/` | 内置 harness 的配置和原生会话 |
| `runtime-home/`、`cache/`、`desktop/`、`logs/` | 隔离运行目录、缓存、桌面状态和日志 |

退出应用后备份整个数据目录，并单独备份实际项目目录。文件产物保存在你选择的项目目录里，应用备份不包含这些文件。加密凭据可能绑定当前系统钥匙串，迁移到另一台电脑时应重新填写密钥。

重启会显示已保存历史，不自动重跑上次活动执行。损坏状态可从应用保留的备份恢复；未知数据版本会阻止启动并保留原文件，不会静默覆盖。恢复前先复制整个目录，再处理备份。磁盘或目录写入失败时会停止后续执行，修复磁盘空间或权限后再重启。

开发和验收可设置 `MESNIER_HOME=/绝对路径/独立目录`。正常使用不需要设置此变量。

## 当前边界

首版覆盖本地文本文件、基础 shell、项目代码、对话和看板。没有自动更新、远程执行、内置 Office 编辑器、浏览器控制、插件市场或跨平台保证。代码任务仍需要该项目所需的编译器、包管理器和依赖；缺少工具会在实际执行中报错。Grep / Glob 首次缺少 ripgrep 时可能需要联网下载固定版本并校验，缓存位于隔离数据目录；无缓存离线搜索尚未实测。

本地测试模型不是应用内置模型，也没有预置到正式用户配置中。安装包、实际验证范围和未覆盖项见 [发行验收](verification/release-0.1.0.md)。
