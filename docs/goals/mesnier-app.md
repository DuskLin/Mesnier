# Mesnier 桌面成品交付目标

在 Mesnier 仓库交付一个可在当前 macOS 电脑安装、双击启动和持续使用的桌面应用，产物命名为 Mesnier。以新版 Kimi Code 源码及其 harness 为默认执行底座，尽量保持上游实现不变，通过 Mesnier 自有模块封装；功能和交互参考 ZCode，看板参考 Multica。应用自己的模型配置、会话、任务、日志和缓存统一使用 `~/.mesnier`，测试使用独立目录。

应用须具备模型设置、工作目录管理、流式对话、工具事件、权限批准与拒绝、取消、历史恢复、基础文件产物查看，以及任务看板。Chat 与 Board 共享同一任务和执行记录，运行结束后由用户验收任务；安装后的运行不依赖开发服务器或用户预装 Kimi CLI。

完成时交付可运行安装包、源码、使用说明和与版本绑定的验证证据。验证覆盖实际界面、Kimi harness 的执行链路、Work/Coding 文件任务，以及失败、拒绝、取消、恢复和数据隔离；修复此前发现的探针判定问题。模拟测试与真实模型验证分别记录，缺失的实测不得算作完成。

全过程使用 OpenSpec 管理范围、设计、任务、验证和归档；按职责安排 Agent 并行开发和交叉审查，各自使用独立 worktree。每个可验证阶段提交或提 PR，检查后合入 main 再继续，不绕过分支保护。若遇到外部阻塞，继续完成独立工作并如实记录，不能以缩小目标或演示版代替成品。

## 完成判据

安装包与源码版本一致；实际安装启动和界面流程有截图与记录；真实 harness 和真实模型分别有证据；Work/Coding 文件变化、权限拒绝无副作用、取消确认、重启不重放、Chat/Board 同一执行、独立数据根均由行为验证证明。所有任务完成并完成交叉审查后归档 OpenSpec。没有证明的项继续保持未完成。
