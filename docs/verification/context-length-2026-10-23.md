# Mesnier 0.1.1 上下文长度修复验收

`200000` 被拒绝是界面 `step=1024` 引起的原生表单错误。宿主原本接受 1024～10000000 的任意整数；本次将输入步长改为 1，并让两个保存按钮共享整数及范围校验，不修改内核、协议或数据格式。该修正恢复既有契约，适用小型修正例外，不另建 OpenSpec 提案。

## 验证对象

- 基准：`681d755cb1f25e3296cffd048ee090fec41a6455`。
- 执行时对象：基准加未提交的 `Settings.tsx`、根 `package.json` 和 `package-lock.json`；后续提交包含同一内容。三份源码、测试文件和构建的 SHA-256 见 [验证摘要](../../tests/ui/evidence/context-length-summary.json)。README、经验和报告文字不进入应用构建。
- 环境：当前 macOS arm64、Electron 41.0.3；应用版本 0.1.1，内置运行时仍为 0.1.0。
- 主执行者与测试执行者使用独立 worktree，测试使用独立 `MESNIER_HOME` 和本机回环 HTTP 服务。
