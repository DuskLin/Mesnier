## 修改与真实复现

- 关闭或磁盘保存失败发生在目录扫描期间时，旧实现会在扫描恢复后发送 `run`。独立审查用真实目录扫描暂停复现了两例；修复登记准备过程、可取消扫描和执行身份门禁，关闭等待准备退出。初始运行状态保存也进入统一捕获，避免 `void pump()` 产生未处理拒绝。
- run 回执超时或早于回执的终态不能重叠后续执行。旧 worker、工具进程组和后台后代经 PID、PGID、出生时间与运行身份核对并停止后，才恢复调度。
- 模型配置先写入新的加密凭据引用再持久化状态；保存失败仍保留旧状态可用的引用。运行中的凭据捕获不受后续换密钥和删除默认配置影响。
- 状态或日志无法保存时停止后续执行，保留中断提示。供应方错误、事件与日志处理原始、URL 和 JSON 转义凭据；事件按值脱敏，不以字符串替换破坏 JSON 结构。
